# CineCritic 🎬

**An AI-powered cinema companion for film analysis, discovery, and personal watchlist management.**

CineCritic helps you explore films beyond their ratings. Get spoiler-aware AI critiques, examine filmmaking craft, discover movies based on your mood, ask questions about cinema, compare two films, and organize what you want to watch.

## Features

- **AI Film Critiques** — Analyze a film with eight filmmaking-craft scorecards and a written critique.
- **Spoiler Protection** — Choose a spoiler level before generating analysis.
- **Film Discovery** — Browse popular, trending, top-rated, and currently playing films.
- **Mood-Based Recommendations** — Describe a mood, story, or the kind of film you want, and get relevant suggestions.
- **Ask the Critic** — Ask questions about a film, cinematic techniques, themes, or what to watch next.
- **Film Battles** — Compare two films across craft-score dimensions, with an AI-written comparison.
- **Personal Watchlist** — Organize films as planned, watching, or watched; mark favourites; add ratings and personal notes.
- **Import and Export** — Move watchlist data using supported file import/export options.
- **Language Preference** — Select a supported response language for AI analysis.
- **Resilient API Handling** — Clear loading/error states and handling for provider timeouts and rate limits.

> AI scores are subjective assessments generated by CineCritic. They are not IMDb scores, audience ratings, or objective judgments of artistic quality.

## Tech Stack

- **Frontend:** React 19, TypeScript, Vite 7
- **Backend:** TypeScript serverless API routes
- **Movie metadata and discovery:** [The Movie Database (TMDB)](https://www.themoviedb.org/)
- **AI providers:** Anthropic, OpenAI, Google Gemini, and Mistral
- **Hosting:** Vercel
- **Testing:** Node.js test runner through `tsx`

## Getting Started

### Requirements

- Node.js **20 or newer**
- npm
- A [TMDB API key](https://www.themoviedb.org/settings/api)
- An API key for at least one supported AI provider

### 1. Clone the repository

```bash
git clone https://github.com/Kartik-pro/CineCritic.git
cd CineCritic
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Copy the example file:

**Windows PowerShell**
```powershell
Copy-Item .env.example .env
```

**macOS / Linux**
```bash
cp .env.example .env
```

Add your own keys to `.env`:

```dotenv
TMDB_API_KEY=your_tmdb_api_key

# Configure at least one AI provider:
GOOGLE_API_KEY=your_google_api_key
# ANTHROPIC_API_KEY=your_anthropic_api_key
# OPENAI_API_KEY=your_openai_api_key
# MISTRAL_API_KEY=your_mistral_api_key

# Optional: choose a provider and model
AI_PROVIDER=gemini
AI_MODEL=gemini-3.5-flash
```

Supported `AI_PROVIDER` values are `anthropic`, `openai`, `gemini`, and `mistral`. The application uses the configured provider's key and supports an optional `AI_MODEL` override. If `AI_PROVIDER` is omitted or invalid, the server checks available provider keys in its built-in order.

Keep API keys private. Never commit your real `.env` file or expose provider keys in frontend code.

### 4. Run locally

The API routes are designed for Vercel's serverless environment, so use the Vercel development server rather than Vite alone.

```bash
npx vercel dev
```

Follow the CLI prompts if this is your first run, then open the local URL shown in the terminal.

For frontend-only development, you can also run:

```bash
npm run dev:web
```

Note: Vite alone does not provide the Vercel API routes used by features that call the backend.

## Deployment

CineCritic includes a `vercel.json` configuration for its API functions.

1. Push the repository to GitHub.
2. Import the repository into [Vercel](https://vercel.com/).
3. Add the required environment variables in **Project Settings → Environment Variables**:
   - `TMDB_API_KEY`
   - At least one AI provider key
   - Optionally, `AI_PROVIDER` and `AI_MODEL`
4. Deploy the project and test the critique, discovery, Ask the Critic, and comparison flows.

Do not put secrets in client-side environment variables. Configure API keys on the server through Vercel's environment settings.
